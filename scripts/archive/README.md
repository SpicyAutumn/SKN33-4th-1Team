# 과거 데이터 인계 도구

`package_aks_handoff.py`는 2026-08-28 당시 첫 10,000 EID의 인계 패키지를 재현하기 위한 도구입니다. 파일명·대상 CSV·설명에 당시 수치가 고정되어 있으며 현재 전체 데이터나 4차 제출본을 패키징하는 도구가 아닙니다.

원본 CSV·JSON과 당시 검증 결과가 준비된 환경에서만 사용합니다. 코드가 프로젝트 루트를 찾으며 출력은 Git에서 제외한 `data/handoff/`에 생성합니다. 보고서 안의 고정 숫자는 새 데이터 실행 결과로 해석하지 않습니다.

현재 데이터 준비는 [전처리 보고서](../../docs/02_data_preprocessing_report.md), 현재 제출은 [4차 실행·제출 안내](../../docs/deliverables/07_release.md)를 따릅니다.
