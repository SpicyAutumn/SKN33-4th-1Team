# 단일 주장 검증: 1차 모델 비교와 후속 방향

2026-09-14. 로컬 실험·사용자 의미 검토를 바탕으로 작성한 요약이다. 서비스 연결·모델 채택 PR이 아니다. 기존 PR #1의 프롬프트 A/B 실험과 별도의 모델 비교이며, 앞선 미개선 결론을 덮어쓰지 않는다.

## 범위와 결과

Ollama 0.34.0에서 동일한 선정8개 주장과 출처를 사용했다. 단일 주장 검증이며 검색 성능·답변 전체 검사·서비스 정확도는 평가하지 않았다.

|---|---:|---:|

| 엄격한 연속 인용 통과 | 5/8 | 7/8 |

위 비율은 종합 통과율이 아니다. Qwen에서 관련 근거 선택, 질문과 대상 연도 구분, 정확한 인용의 개선을 관측했다. C01은 Qwen 라벨·인용 오류와 설명 일반화, EXAONE 인용·설명 문제가 남았다. Qwen C05는 핵심 판정·인용은 적합하나 설명 재서술 주의가 남았다. EXAONE C03·C04·C06은 정확한 인용만으로 의미 적합성을 보장할 수 없음을 보여 주었다. Q-C06 보조 근거 배열 미수록은 주석이며 사후 오류 규칙을 추가하지 않았다.

Qwen은 후속 검증 후보로 유지하고 일반 우위·운영 채택은 보류한다. EXAONE을 운영용으로 확정한 것도 아니다.

## 실행 상태와 한계

기존 Qwen 첫 요청은 300초 내 적재 미완료로 중단됐으며 후속7개는 미실행이다. 별도 B2 준비 요청은 약46.34초에 완료됐고 이후8개 응답을 확보했다. 보완 성공은 기존 실패를 대체하지 않는다. 원래 지연의 근본 원인은 미확정이다.

평가용 전송17건(E8 + 기존Q1 + 보완Q8), 완료16건, 답변 없는 준비1건 별도. 예정 슬롯24개에 미실행7개가 포함되므로 24회 호출이 아니다. 자동 재시도와 임베딩·검색 호출은 이 비교 범위에서 없었다.

실행 세션의 드라이버·CUDA·표시 VRAM·적재·캐시가 달라 첫 응답 속도의 직접 비교는 하지 않는다. 선정8사례 각1회라는 한계가 있다. 소표본 일치율을 일반 정확도나 합격선으로 사용하지 않는다.

## 확정된 평가 원칙

1. 질문·다른 문장의 오류를 대상 주장에 전가하지 않는다.
2. 인용은 정확한 연속 문자열로 검사한다. 원문에 실제 있는 생략표는 허용하지만 새 생략표·줄바꿈 보정·재배열은 허용하지 않는다.
3. 인용 정확성과 의미상 관련성·충분성을 분리한다.
4. 자료 부재와 역사적 사실 부재를 구분하고 해석 불확실성을 남긴다. 기준 소급 변경은 하지 않는다.
5. 라벨·근거·설명을 함께 검토하며 보조 근거 누락은 기존 합의대로 별도 기록한다.
6. 실행·자동 검사·사용자 의미 검토를 구별한다. 검토 의견에 대한 동의는 모델 정답과 다르다.

## 공개 코드와 비공개 근거의 경계

원문 응답·출처 묶음·서버 로그·개인 경로는 포함하지 않았다. 따라서 이 PR만으로 실제16개 응답 집계를 독립 재계산할 수는 없다. 표는 로컬 보존 자료에 대한 사용자 검토 완료 요약이며, 공개 테스트로 실증된 모델 성능이라고 주장하지 않는다.

`experiments/semantic_verifier/offline_record.py`는 기존 validate를 재사용하는 작은 기록 도우미다. 합성 테스트만으로 실행·인용·의미 검토 분리와 덮어쓰기 거부를 확인할 수 있다. 비공개 세션 전용 어댑터와 로컬 수용 테스트16개 전체를 공개한 것이 아니다. 승인 참조는 호출자가 전달하며, 이 도우미가 승인 문서의 진위를 검증하지 않는다. 파일 해시 검사는 명시적으로 호출해야 한다.

실행: 저장소 루트에서 아래 명령. Python 표준 라이브러리만 사용하며 모델 요청을 보내지 않는다.

```bash
python -X utf8 -B -m unittest discover -s experiments/semantic_verifier -p "test_*.py"
```

## 후속 잠정 방향

- 내부 평가 용도로 준비하며 사용자 답변 자동 수정·차단은 하지 않는다.
- 기존8개는 회귀 자료로 보존하고 새 독립 후보를 별도로 수집·검토한다. 현재 PR에는 새 후보가 없다.
- 정상 지지·명시적 모순·근거 부족·질문 전제 혼동·하위 순위 근거·장문·모호한 문맥을 포함하는 방향으로 준비한다. 실제/합성 자료를 구분한다.
- 추가 호출·공용 자원 사용·서비스 연결은 별도 계획과 관련 담당자 확인 후 진행한다. 팀 전체 합의 완료를 뜻하지 않는다.
- 새 자료 검토 후 실행 수·비용·준비 조건을 정한다. 이전 실험의 예산과 호출 승인을 자동 이월하지 않는다.
