## 로컬 실행

frontend에서 기존 lockfile로 의존성을 설치한 후:

```powershell
npm ci
npm run dev -- --config vite.review.config.js
```

- http://127.0.0.1:5174/ : 실제 API 연결. 기존 서비스가 127.0.0.1:8081에서 실행 중이어야 한다.
- http://127.0.0.1:5174/history-review.html : 가상 데이터 검증. 실제 API/회원 DB/AI 미사용.
- 검증 설정은 loopback에만 바인딩하고 알려진 개발 Origin만 기존 API Origin으로 매핑한다.
- 실제 화면에서 로그인 후 검색/제보하면 기존 DB에 기록될 수 있다.
- 검증 HTML은 기본 프로덕션 빌드 진입점에 포함되지 않는다.

검증 화면의 ‘화면 확인’으로 사진 있음/없음/로드 실패/로딩/PR #20 제보/전송 실패를 선택한다.
가상 제보는 검증 요청 내역에만 기록된다.
