검토용 PR을 등록한다. 실제 회원 연결 등 미검증이 남으면 초안 PR에 명시하고,
병합 가능 상태로 판단하기 전에 확인한다. 날짜를 임의로 확정하지 않는다.

## 사진·자동 전환 반영 메모

- 기존 검증 자료와 SHA-256 일치 확인 후 21개 파일 복사: 합계 9,346,300바이트.
- 19개 공공누리 제1유형, 2개 Commons 사진의 개별 라이선스와 저작자 보존.
- 별도 이미지 파일로 제공하며 전체 사진을 JS에 base64로 포함하지 않는다.
- 현재 3개만 DOM에 배치하고 lazy loading 사용. 자동 전환은 AI/API 요청 없음.
- 10초마다 직전 3개를 제외해 선택. 페이지 비활성, 화면 밖, hover, focus,
  사진 설명 펼침, 동작 줄이기 설정에서는 전환을 멈춘다. 수동 멈춤도 제공한다.
- 실제 관심사 데이터가 없으므로 추천 배지는 표시하지 않는다.
- 출처·저작자·라이선스는 카드에 표시하며 촬영 시점 등 설명은 펼쳐 볼 수 있다.
- 사진 HTTP 응답 21/21 정상, 프로덕션 빌드 통과. 좁은 화면의 사진/출처 표시 확인.
- 실제 타이머 및 모든 화면 폭 조작 검증은 아직 남아 있다.

## 로딩·답변 사진 연결

- `HeritageLoading`: V21의 개념도 경로와 지역 표시 좌표를 재사용했다. 실제 위치 좌표나
  검색 근거가 아님을 안내한다. 21개를 섞어 한 바퀴 내 중복 없이 6초 간격으로 소개하고,
  사진 출처/이용 조건/설명을 표시한다. 자동 넘김 멈춤과 다음 버튼을 제공한다.
- 페이지 비활성/동작 줄이기/마우스 올림/키보드 포커스 중에는 자동 넘김을 멈춘다.
  저장 기록 조회에는 이 소개를 띄우지 않고 짧은 조회 안내만 표시한다.
- `AnswerMediaLayout`: `media[].document_id`가 근거 문서와 일치하는 이미지만 사용한다.
  대표 사진 우선, URL 중복 제거, 사진별 출처·이용 유형, 여러 사진 선택을 지원한다.
- 사진은 자르지 않는 contain 배치다. 사진이 없거나 모두 실패하면 사진 칸을 없애고
  답변을 전체 폭으로 표시한다. 760px 이하에서는 사진 다음에 답변, 그 아래 근거를 둔다.
- 질문 제목으로 21개 사진을 임의 연결하지 않는다. 현재 main 백엔드가 media를 반환하지
  않으면 사진이 표시되지 않는 것이 정상이다. PR #16의 백엔드는 이번에 병합하지 않았다.
- 검증 화면 상단의 ‘화면 확인’에서 로딩/사진 있음/없음/로드 실패를 선택할 수 있다.
  여기의 답변은 검증 데이터이며 실제 AI·회원 DB를 호출하지 않는다.

검증: 프로덕션 빌드, 검증 진입점 번들, 문서 일치/URL/라이선스 필터/사진 중복/
대표 사진 우선 및 출처 렌더링 검사를 통과했다.

```powershell
node frontend/scripts/check-answer-media.cjs
```

남은 확인: 실제 브라우저에서 사진 실패 후 칸 제거, 이전/다음 사진, 자동 넘김,
PC/모바일 레이아웃 및 #16 적용 백엔드의 실제 사진 응답. 이번 단계에서는
프롬프트·모델·DB·실행 중인 컨테이너를 변경하지 않았다.

## 오류 제보 패널 연결 — 최신 시안

세부 규칙과 담당자 협의 사항은 [오류 제보 UI 현행안](ERROR_REPORT_UI_SPEC.md)을 기준으로 합니다.

- 일반 테스트: 유형 드롭다운 1개 필수, 설명 기본 선택·기타만 필수(공백 불가), 최대 2,000자.
- 운영 연결: 기존 category 1개 및 모든 유형 설명 10~2,000자 유지. 백엔드 준비 전 임의 전환하지 않음.
- 캡처: Win + Shift + S로 범위 선택 후 Ctrl + V로 미리보기. 이미지 1개·5MB 이하, 삭제·교체 지원. 서버 업로드 없음.
- 모바일: 상단 접기·닫기 고정, 패널 내부 스크롤 허용. 긴 내용과 키보드 표시 시 실제 기기 검사 필요.
- ‘PR #20 오류 제보’는 기존 복수 유형/선택 문구 계약의 비교 모드이며 일반 시안과 별개.
- 문구·설명은 접기/닫기 시 유지하지만 캡처 미리보기는 제거됨. 실제 첨부 유지 정책은 후속 구현 시 보완.
- 실제 오류 제보 제출은 미실행. 가상 테스트에서 기타 설명 누락 차단과 일반 유형 설명 생략 허용 확인.
