# 회원 탈퇴와 삭제 범위 점검

확인일: 2026-09-23 · 기준: main `7811a717` (PR #46 포함)

이 문서는 저장소 코드의 정적 검토 결과다. 운영 DB, 서버 파일, 클라우드 콘솔 및 공급자 계정 설정을 열람하거나 실제 회원을 삭제하지 않았다. 아래의 ‘확인’은 코드 동작에 대한 확인이며 실제 배포·보관 상태의 확인을 뜻하지 않는다.

| 대상 | 코드에서 확인한 처리 | 근거 |
| --- | --- | --- |
| 회원 DB | 비밀번호·‘탈퇴’ 문구 확인 후 트랜잭션으로 본인 제보, 검색 기록, 세션, 회원 삭제 | `backend/api/views.py`의 `my_profile` |
| 근거·저장 답변·공유 링크 | 연쇄 삭제로 회원 소유 답변도 삭제되어 공유 조회 불가 | `backend/api/models.py`, `backend/api/search_links.py` |
| 비회원 답변 | 회원과 연결되지 않아 회원 탈퇴 대상 아님. 쿠키 만료는 DB 삭제가 아님 | `backend/api/search_links.py` |
| 관리자 처리 이력 | 다른 회원의 제보는 유지하고 탈퇴한 처리자 연결만 비움 | `ErrorReport.handled_by`의 `SET_NULL` |
| 테스트 서버 백업 | 마이그레이션 전 `before-migrate.sql` 생성, 이전 백업은 수동 복구용으로 유지. 탈퇴와 연동한 삭제 없음 | `scripts/integration/server.py`의 `backup_database`, 마지막 보존 주석 |
| 테스트용 DB 복제 | 이메일·이름·비밀번호·텍스트·공유 토큰 등을 치환하고 세션 제외. 회원 ID·시각 등 일부 값 유지. 완전 익명화로 단정할 수 없으며 탈퇴 연동 삭제 없음 | `scripts/integration/clone_database.py`의 `sanitize`, `scrub_json` |
| 서버 로그 | 테스트 컨테이너 로그는 크기 순환 설정(10MB × 2). 기간 만료나 회원별 삭제가 아님. 운영 로그의 실제 내용·보관 기간은 미확인 | `scripts/integration/server.py`의 `compose_config`; `deploy/nginx-https.conf`, `frontend/nginx.conf` |
| 외부 서비스 | OpenAI 임베딩, Pinecone 검색, Ollama 생성 호출 경로 존재. 탈퇴 처리에 외부 기록 삭제 호출 없음 | `src/rag_indexing/pinecone_store.py`, `src/rag_service/ollama_generator.py`, `my_profile` |

## 병합 전 운영 담당자 확인

| 확인 항목 | 필요한 답변·조치 |
| --- | --- |
| 운영·테스트 백업과 클라우드 스냅샷 | 실제 존재 위치, 접근자, 보관 기간, 파기 방식 확인. 백업 복원 시 탈퇴 정보가 되살아나지 않도록 재삭제 절차 결정 |
| 로그·모니터링 | Nginx·앱·Docker·클라우드 로그에 IP, 질문, 답변, 공유 경로 등이 남는지와 보관 기간 확인. 비밀 값이나 원문 로그를 PR에 첨부하지 않기 |
| 외부 서비스 | 실제 공급자·리전·전송 항목·계정별 보관 설정 및 삭제 요청 가능 여부 확인. 회원 탈퇴만으로 공급자 기록이 지워진다고 안내하지 않기 |
| 테스트 복제본 | 복제 파일·복원 DB·추가 백업의 보관 종료 시점과 관리 책임 결정 |
| 정책 확정 | 확인 결과에 맞춰 보관 기간·파기 절차·외부 처리 안내 보완 후 팀원 1명 이상 검토 |

OpenAI 공식 데이터 안내는 임베딩 API의 기본 남용 모니터링 로그와 조직별 데이터 제어 설정을 구분한다. 이를 우리 계정에 그대로 적용된 것으로 가정하지 않는다: [공식 데이터 관리 안내](https://developers.openai.com/api/docs/guides/your-data).

이번 변경은 약관과 개인정보 처리방침의 ‘탈퇴 기능 없음’ 안내를 바로잡고 서비스 DB 삭제와 별도 보관 기록을 구분한다. 삭제 기능, DB 스키마, RAG, 프롬프트 및 모델은 변경하지 않는다. 운영 확인 전까지 PR은 초안 상태로 유지한다.
