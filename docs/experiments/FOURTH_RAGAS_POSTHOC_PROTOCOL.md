## 공식 구현 대조

실행 환경: `<로컬 작업 폴더>/.venv`, RAGAS 0.4.3.

공식 저장소 `vibrantlabsai/ragas`의 `v0.4.3` 태그에서 아래 네 파일을 내려받아 설치 파일과 줄바꿈을 정규화한 텍스트 SHA-256을 비교했다. **4개 모두 일치**한다.

- `metrics/collections/faithfulness/metric.py`
- `metrics/collections/faithfulness/util.py`
- `metrics/collections/answer_relevancy/metric.py`
- `metrics/collections/answer_relevancy/util.py`

파일별 공식 URL과 해시: `experiments/qwen_ragas_posthoc/official_source_audit.json`.

저장소의 `src/evaluation/ragas_evaluator.py`는 공식 `Faithfulness`와 `AnswerRelevancy`를 직접 호출한다. Faithfulness는 추출한 주장 중 제공 문맥이 뒷받침하는 비율이다. AnswerRelevancy는 답변에서 기본 3개의 역질문을 생성하고 원질문과 임베딩 코사인 유사도를 계산한다. 공식 0.4.3 구현은 생성된 질문의 noncommittal 플래그가 모두 참일 때 관련성 점수를 0으로 처리한다.

## 저장소 래퍼의 변경점

1. AnswerRelevancy의 LLM 입력 앞에 답변과 같은 언어로 역질문을 만들라는 지시를 추가한다. 원질문은 이 단계에 추가하지 않는다. 수식은 동일하지만 프롬프트 조건은 공식 기본값과 다르며 점수에 영향을 줄 수 있다.
2. Faithfulness의 기본 평가 프롬프트와 계산식은 바꾸지 않는다.
3. 평가 모델·임베딩 모델, 토큰 상한·타임아웃·재시도, 검색 문맥 정렬, 비유한 점수/실패 상태 처리는 프로젝트 래퍼에서 설정한다.
4. VertexAI import 호환 처리는 OpenAI 경로의 실행을 위한 것이며 두 지표의 수식이나 프롬프트를 수정하지 않는다.
5. 현재 두 지표에 `reference`는 사용되지 않으며 Context Precision/Recall은 계산하지 않는다. 일부 참조 없는 검색 지표 변형도 있으므로 모든 검색 지표가 반드시 기준 답안을 요구한다고 일반화하지 않는다.

정확한 설명: **공식 RAGAS 지표를 사용하되, 저장소의 Answer Relevancy에는 한국어 대응 지시가 추가된 평가기**이다. 모든 평가 조건이 공식 기본값과 동일하다고 표기하지 않는다.

## 사후 비교에 동결한 조건

- 이번 비교는 공식 0.4.3 기본 프롬프트를 사용한다. 동일 언어 추가 지시는 사용하지 않는다.
- 설정된 평가 모델: `gpt-4.1-mini-2025-04-14`; 임베딩: `text-embedding-3-small`.
- Dev 및 재사용 Holdout 각각 일반 답변 기대 20건·정정 기대 20건 전부: 80문항, EXAONE/Qwen 최종 메시지 160개.
- 실제 유형이나 과거 성공 여부로 선택하지 않는다. 거절·되묻기 기대 유형은 이 두 지표의 주 평가에서 제외한다.
- 최종 서비스 `message`를 그대로 평가한다. 모델 이름·유형 라벨·기존 검토 결과·원시 생성 프롬프트는 평가 입력에 넣지 않는다. 별도 정정 필드의 완전성은 이 점수의 측정 대상이 아니다.
- 같은 질문에 같은 검색 문맥을 제공한다. 답변 재생성, 검색 재실행, 운영 코드 변경은 하지 않는다.
- 평가 실패·정의되지 않은 점수를 0으로 대체하지 않는다. 유효한 쌍 수를 공개하고, 양쪽 모두 실질 답변 유형인 경우도 별도 분석한다. 정직한 유보를 환각이나 과업 성공으로 단순 환산하지 않는다.
- 공식 프롬프트의 역질문 언어는 고정하지 않는다. 생성 언어와 역질문을 기록해 언어 차이가 점수에 미친 가능성을 검토한다.
- 두 데이터셋과 일반/정정 그룹은 별도 집계한다. 단일 평가 모델 결과를 독립적인 사람 검수나 전체 사실 정확도로 부르지 않는다.

## 재개 및 추가 진단 기록

사용자가 현재 대화에서 “방금 동의 했는데?”라고 전송·비용 사용 승인을 확인하여 평가를 재개했다. 공식 기본 평가 160응답·320지표가 모두 완료됐으며 호출 실패는 없었다.
