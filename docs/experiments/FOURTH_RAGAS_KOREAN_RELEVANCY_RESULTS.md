# 한국어 역질문 조건의 AnswerRelevancy 재평가

> 공유 안내: 이 문서는 실행 당시의 결과 기록입니다. Dev120·Holdout120 질문 세트는 팀 Google Drive에 ZIP으로 공유했습니다. 문서에 언급된 `outputs/`·`experiments/` 원자료는 로컬 보관이며 이 문서 PR에 포함하지 않습니다. 당시의 미게시·후속 평가 미실행 표기는 해당 기록 작성 시점을 뜻합니다. 최신 종합 판단은 [모델 전환 제안](FOURTH_QWEN_BASELINE_RECOMMENDATION.md)을 참고해 주세요.

2026-09-18 KST. 이전 공식 기본 프롬프트의0.3대 점수에 역질문 언어가 영향을 주었는지 확인하기 위한 보완 평가다. 기존 결과는 변경하지 않았다.

## 고정한 조건

- 기존 평가의 동일한240개 저장 응답: EXAONE·Qwen 각각 Dev40/Holdout40, LangChain·LangGraph 각각 Dev40. Qwen Dev40은 프레임워크 비교에도 재사용한다. 각40은 일반 답변 기대20·정정 기대20이며 각120문항 전체 점수가 아니다.
- AnswerRelevancy만 재평가했다. Faithfulness, 답변 생성, 검색은 다시 수행하지 않았다. 기존 실제 서비스의 응답을 수정하지 않았다.
- 공식 RAGAS0.4.3의 원래 프롬프트에 아래 문구만 앞에 추가했다. 공식 예시·출력 schema·점수 수식·strictness3은 그대로다. 공식 기본 프롬프트 결과와 구분하여 **한국어 역질문 조건의 보완 평가**로 표기한다.

```
Generate the question in Korean (한국어), the language of the response. Keep the original proper names where appropriate.
```

- 평가 모델 gpt-4.1-mini-2025-04-14, 임베딩 text-embedding-3-small, temperature0, max_tokens4096, 문항 병렬4. 질문 순서 seed20260918. 출력 결과에 따른 선별 재채점은 없다.
- 평가 모델에는 저장 답변과 위의 언어 지시·공식 지표 프롬프트만 제공했다. 원질문은 임베딩 비교에 사용했고 정답 라벨·모델 이름·이전 점수는 평가 모델에 전달하지 않았다.
- 역질문을 새로 만들었으므로 질문 표현과 noncommittal 판정도 변할 수 있다. 영어 역질문의 단순 번역만 비교한 실험은 아니며 모든 증가분을 언어 차이 하나의 순수 인과 효과로 분해할 수는 없다.

## 결과 해석과 PR 반영

한국어 역질문 지시를 적용하자 모든 그룹 평균이 +0.2203~+0.3351 상승했다. 역질문720개 모두 한글을 포함한다. 전후 모두 유보0점이 아닌 응답만 보아도 모든 그룹에서 +0.2608~+0.3385 상승했다. 따라서 소수 유보 판정의 변화만으로 생긴 상승이 아니며, 기존 낮은 절대 점수에 평가 언어 설정이 상당한 영향을 줬다는 해석을 뒷받침한다. 다만 새 역질문의 내용 변화까지 포함된 민감도 실험이라는 한계는 유지한다.

**AnswerRelevancy가 Qwen 전환의 일관된 우위를 보여준다는 주장은 지지되지 않는다.** Dev에서는 EXAONE0.6815 > Qwen0.5909이며 차이 구간도0 미만이다. Holdout에서는 EXAONE0.5887 < Qwen0.6170이나 차이 구간에0이 포함된다. PR에는 이 불리하거나 불확실한 결과도 함께 기재해야 한다. 기존 유형·행동 평가와 Faithfulness의 개선 근거를 답변 관련성의 개선으로 혼동하면 안 된다.

프레임워크 비교에서는 Qwen0.5909, Chain0.6009, Graph0.6226이다. Graph의 평균 관련성 방향은 기존 조건과 반대로 나타났지만, 두 후보 모두 Qwen과의 차이 구간에0이 포함된다. 기존 조건의 관련성 하락을 확정적 Graph 열위로 표현하지 않으며, 새 조건의 상승도 확정적 품질 개선으로 표현하지 않는다. 별도 Faithfulness·내용 검토·비용 결과는 그대로 남는다.

대표 사례를 원응답과 역질문으로 확인했다. 이는 정성 설명이며 점수를 수동 변경하지 않았다.

- Dev034 나전칠기: EXAONE은 자개로 무늬를 만든다고 답해0.8020, Qwen은 근거에 자개가 있어도 명확히 답할 수 없다고 유보해0점이다. Qwen의 실제 불필요한 유보가 드러난 사례다. EXAONE 부연의 근거 적합성까지 이 지표가 보증하지는 않는다.
- Dev040 동학: EXAONE은 제공 근거에 없는 창도자를 답해0.6549, Qwen은 정당하게 유보해0점이다. 질문에 직접 답하는 성향을 보상하는 지표가 근거 준수와 충돌하는 사례다. Dev034와 동일하게 해석하면 안 된다.
- Dev027 해녀: baseline0.6784, Graph0.9804. 두 답변 모두 산소통 없이 물질한다고 설명한다. baseline 역질문은 작업 방식을 묻고, 전제를 명시적으로 인용한 Graph에서는 원질문에 가까운 산소통 여부를 묻는 역질문이 나왔다. 역질문 표현이 내용 품질 차이 이상으로 점수 차이를 만들 수 있다. Dev026 판소리에서도 비슷한 현상이 확인됐다.

## 해석상 한계

- 기존0.3대 절대값을 서비스 답변의 낮은 관련성으로 단정하면 안 된다. 동일 언어 지시를 적용한 결과와 나란히 제시해야 한다.
- 이 지표는 답변에서 생성한 질문과 원질문의 의미 유사도다. 사실 오류, 근거 없는 정정, 대상 혼동이나 과업 성공을 직접 판정하지 않는다. 점수 상승만으로 모델 답변 자체가 개선됐다고 주장할 수 없다. 답변은 재생성하지 않았다.
- 정당한 근거 부족 안내도 noncommittal로 판정되면0점이 될 수 있다. summary.json에는 유보 처리 전 평균 cosine과 전후 유보 전환, 양쪽 모두 유보로 판정되지 않은 문항의 변화도 보존했다. 이를 주 분석 대신 선택적으로 보고하지 않는다.
- Dev는 개선에 사용된 문항이며 holdout도 이미 사용한 문항을 사후 평가한 것이다. 독립적인 신규 holdout 검증이라고 주장하지 않는다. LangChain/LangGraph holdout 점수는 없다.
- 기존 Faithfulness와 유형 일치·내용 검토 결과는 별개로 유지한다. 현재 평가 조건의 변경으로 해당 기록을 대체하지 않는다.
