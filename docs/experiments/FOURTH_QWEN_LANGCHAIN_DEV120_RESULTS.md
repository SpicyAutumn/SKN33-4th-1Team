> 공유 안내: 이 문서는 실행 당시의 결과 기록입니다. Dev120·Holdout120 질문 세트는 팀 Google Drive에 ZIP으로 공유했습니다. 문서에 언급된 `outputs/`·`experiments/` 원자료는 로컬 보관이며 이 문서 PR에 포함하지 않습니다. 당시의 미게시·후속 평가 미실행 표기는 해당 기록 작성 시점을 뜻합니다. 최신 종합 판단은 [모델 전환 제안](FOURTH_QWEN_BASELINE_RECOMMENDATION.md)을 참고해 주세요.

2026-09-18 KST. `feature/langgraph-response-state`의 별도 worktree에서 실행했다. 메인, Docker, .env, 서비스 소스에는 이번 실험의 변경을 적용하지 않았다.

**일괄 인접 본문 보충으로 일반 답변의 근거는 개선됐지만, 목표였던 정정·되묻기의 의미 판단 개선은 확인하지 못했다. 현재 버전을 품질 개선안으로 채택하거나 holdout으로 승격할 근거는 부족하다.**

## 무엇을 비교했는가

1. 단순 LangChain LCEL 연결: 기존 Qwen baseline의 저장 요청·원응답으로 120건 모두 요청 및 서비스 출력 동등성을 확인했다. 이 결과는 오프라인 재생이며 새로운 실시간 120건 반복이 아니다.
2. 실제 모델 평가: 동결된 baseline 검색 결과 top_k=3 → 기존 LangChain 인접 본문 보충 → 기존 baseline 생성기 및 서비스 후처리. 같은 문서 ID·fingerprint·출처의 본문을 최대 3개 더 붙였다. 최대 6개이며 9,000자는 **본문 문자 수** 제한이다. 원래 검색 결과는 자르지 않는다.

따라서 품질 변화의 실험 처치는 **문맥 보충**이다. LangChain 프레임워크 자체의 효과나 검색 알고리즘의 개선으로 해석하지 않는다. 과거 저장된 최종 검색 결과를 사용하여 Pinecone/BM25의 새 검색은 실행하지 않았다. 병렬 검색·융합·인접 본문 관련 기존 오프라인 테스트 9개는 통과했다.

- 모델: 기존과 같은 Qwen3.8:27b, 동일 digest 확인, thinking=false, temperature=0, 출력 한도 640.
- 기존 시스템 프롬프트·출력 계약·서비스 규칙 유지. 변경된 것은 user 입력의 검색 문맥이다.
- 신규 모델 호출 106회, 모델을 호출하지 않는 경로 14건. 재시도·검수기·리랭커·추가 LLM 없음.
- 총 104문항에서 문맥이 늘었으며, 모델 호출 대상 중에는 101문항의 payload가 변경됐다. 나머지 모델 호출 5건은 동일 입력을 새로 호출했다.
- 문항 순서·초기 draft 기대 유형·기존 평가 기준을 유지했다. baseline은 앞서 저장한 Qwen Dev120 결과다. 동일 세션의 재생 결과와 별도로 실제 응답에는 표현 변동이 있을 수 있다.
- LangGraph 평가에서 쓴 판단/작성 2단계 및 답변 상태/정정 여부 분리 계약은 이번 실험에 사용하지 않았다.

유형 기준 개선 3건, 회귀 0건이다. 008 독립신문 발행 언어와 020 민요 아리랑 전승은 실제 답변에 필요한 본문이 추가되어 근거 부족에서 답변으로 바뀌었다. 110 이번 달 전주행 최저가 기차표는 근거 부족에서 실시간 예약 서비스 범위 밖으로 바뀌었다. 110은 검색 정보로 표를 찾은 것이 아니라 서비스 범위를 올바르게 안내한 변화다.

이 숫자는 전체 답변의 사실 정확도나 의미 판단 성공률이 아니다. 예컨대 동일한 corrected_premise여도 다른 문서의 사실을 대상에 잘못 붙이는 오류는 점수에 드러나지 않는다.

## 정정·되묻기 동일 40건의 근거/행동 검토

기존 기준에 따라 Codex가 각 응답을 해당 실행에 제공된 문맥과 대조했다. baseline 판정은 이전 기록을 유지했다. 독립된 사람의 블라인드 검수나 자동 LLM 평가가 아니다.

| 검토 묶음 | Qwen baseline 완전 성공 | 이번 완전 성공 |
|---|---:|---:|
| 정정 20건 | 16 | 16 |
| 되묻기 20건 | 16 | 15 |
| 합계 | **32/40** | **31/40** |

- 030 앙부일구: 근거 없는 수시(水時) 부연이 사라지고 해당 문서의 영침·수영면 설명으로 바뀌어 partial→pass.
- 035 거문고: 핵심 정정은 맞지만 제공 문맥에 없는 대금·피리의 관악기 분류를 부연하여 엄격한 근거 준수에서 pass→partial. 세계 지식상 틀렸다는 뜻은 아니다. 이런 상식 부연을 허용하면 이번 정정 성공은 17건, 전체 32/40으로 baseline과 같다.
- 068 세금 제도: 시기는 확인하지만 야간통행금지·벌칙, 예금보험 등 세금이 아닌 제도를 선택지로 제시하여 pass→partial.
- 021 고인돌: 집이 아니라 무덤이라는 정정은 유지되나 돌널무덤의 분포를 고인돌에 전이하는 오류가 남았다.
- 034 나전칠기: 자개 문양 근거를 인지하면서도 금박만 쓴다는 전제를 반박하지 못했다.
- 067 도산서원: 창건 연도를 묻는 사용자에게 창건 연도로 대상을 고르게 하는 선택지가 남았다. 보충할 인접 문서가 없었다.
- 071 글의 작자: 목활자인 방홍무정운대자를 글로 취급하는 선택지 오류가 남았다. 이 문항 역시 추가 본문이 없었다.
- 077/080 복합 질문: 근거 부족으로 종료하고 사전 정책의 질문 분리·선택 요청은 수행하지 못했다.
- 040 동학 창도자: 필요한 인물 근거가 없어서 적절히 유보했다. 과업 성공에는 포함하지 않되 근거 없는 정정으로 평가하지 않았다.

037의 역사적 춤 도구/현행 규모 서술, 076의 clarification.question 원질문 반복은 별도 경계 메모를 남겼다. 전체 응답의 행동과 근거를 기준으로 pass를 주었으나 더 엄격한 시점·필드 기준에서는 낮아질 수 있다. 경계 판정을 완화하더라도 명확한 의미 성능 향상이라는 결론은 나오지 않는다. 1건 차이를 통계적으로 확정된 성능 저하로 해석하지도 않는다.

일반 질문의 선별 검토에서는 005 대동법의 1594년/1608년 혼동, 015 김장 관련 오독, 018 갑신정변의 폐립 유언비어를 목표로 단정한 오류가 줄었다. 이 검토는 20개 일반 질문 전체의 새 정확도 점수가 아니며 정정·되묻기 40건과 합산하지 않는다. 세부 설명과 남은 한계는 selected_normal_review.json에 있다.

HTTP 시간은 모델 요청부터 응답 수신까지다. 실제 검색이나 Docker/프론트 왕복을 포함한 사용자 응답 시간이 아니다. 과거 baseline과 순차 실행한 비교이며 서버 부하·캐시를 통제한 교차 반복 실험은 아니다.

이번 원응답 형식 불일치 29건은 모두 related_topic_candidates를 비워야 하는 계약 위반이다(baseline 17건). 기존 서비스가 제거하므로 최종 실행 오류는 없지만 원응답 계약 준수는 낮아졌다. 생각 출력은 0건, 모든 106회 응답은 stop으로 종료했다.

최종 인용 88개는 연결된 입력 chunk의 문구·제목·문서 ID·출처와 모두 일치했으며 그중 35개는 보충 본문을 인용했다. 선택지의 출처 참조 55개도 입력에 존재했다. 이는 **출처 연결** 검증으로, 해당 인용이 답변의 모든 주장을 의미상 뒷받침한다는 보장은 아니다.

## 판단과 보존

일반 질문에서 정의만 검색되어 답하지 못한 경우에는 본문 보충의 효용이 확인됐다. 그러나 전 문항에 일괄 적용하면 비용이 늘고, 잘못 검색된 대상 주변을 더 가져오거나 무관한 문맥을 선택지에 섞는 문제가 남는다. 이번 방식의 전면 적용을 권장하지 않는다. 후속 후보를 만든다면 필요한 문서 본문을 선택적으로 보충하는 방향을 검증할 근거는 있으나, 아직 검증한 기능으로 간주하지 않는다.

직전 LangGraph Dev120도 유형 적중 107/120, 동일 40건 주 판정 31/40이었다. 하지만 LangGraph는 입력 계약과 호출 구조가 다른 142회 평가였고 이번은 106회이므로, 같은 총점만으로 두 프레임워크의 성능이 같다고 판단할 수 없다.

- 실험 코드와 검토: `experiments/qwen_chain_dev120/`
- 동결 입력·계획·원응답·집계·근거 대조 자료: `outputs/qwen_chain_dev120/v1/`
- 핵심 파일: `cases.json`, `plan.json`, `runtime.json`, `results.jsonl`, `calls/`, `summary.json`, `review_evidence.md`, `behavior_review.json`, `review_summary.json`, `manifest.json`
- 입력 및 기준 코드 14개 해시, SQLite 해시 불변 확인. 원응답 요청/응답 106쌍 보존.
- 새 holdout은 실행하지 않았다. 저장 기록을 남긴 상태이며 메인/서비스 적용·커밋·푸시는 하지 않았다.
