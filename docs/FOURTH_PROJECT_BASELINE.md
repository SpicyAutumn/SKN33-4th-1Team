# 4차 프로젝트 출발 기준

이 저장소는 3차 프로젝트의 확정 제출 커밋 `18b88da95d77eb07c5055dd2769f215df7024bb0`에 포함된 추적 파일을 새 Git 이력으로 이관했습니다.

- 원본: https://github.com/SpicyAutumn/SKN33-3rd-1Team
- 원 기여자: 채수환, 김유진, 권세진, 신가을, 이준희, 김문규 및 원본 저장소의 기여 이력 참조.
- 재사용: 수집·검색·서비스·UI 코드, 계약, 테스트, 실행 안내, 기존 평가 문서.
- 기존 문서·PDF·평가 수치는 3차 기준선입니다. 4차 성과로 표시하지 않습니다.
- 코드·자료의 기존 권리와 출처 조건을 유지하며 이관이 새로운 이용 허락을 부여하지 않습니다. 공개 범위는 팀 확인 후 결정합니다.
- 개인 API 키, `.env`, 가상환경, 원본 데이터, 3차 로컬 미커밋 실험은 초기 커밋에 포함하지 않습니다.
- `_local/`은 Git 추적 제외입니다. 미확정 Prompt와 평가 준비 자료는 이곳에서 검토 후 필요한 부분만 별도 반영합니다.

## 다음 순서

1. 준비된 P0/P1/P2 Prompt 및 18개 수준별 표본·4개 견고성 표본 검토.
2. 팀 저장소 권한과 모델·서버·예산 합의. 현재 3차 담당 표기는 기여 기록이며 4차 담당 확정이 아닙니다.
3. 검토된 조건으로 고정 문맥 실행 도구 구현 및 소규모 Baseline 비교.
4. 결과에 따른 개선·회귀 검증·발표 준비.

새 환경의 실제 모델·DB 연결은 아직 검증하지 않았습니다. 3차 실행 안내를 참고하되 사용하는 데이터와 모델의 버전을 먼저 확인해야 합니다.
