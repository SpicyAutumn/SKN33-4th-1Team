# EXAONE → Qwen 사후 RAGAS 평가 결과

> 공유 안내: 이 문서는 실행 당시의 결과 기록입니다. Dev120·Holdout120 질문 세트는 팀 Google Drive에 ZIP으로 공유했습니다. 문서에 언급된 `outputs/`·`experiments/` 원자료는 로컬 보관이며 이 문서 PR에 포함하지 않습니다. 당시의 미게시·후속 평가 미실행 표기는 해당 기록 작성 시점을 뜻합니다. 최신 종합 판단은 [모델 전환 제안](FOURTH_QWEN_BASELINE_RECOMMENDATION.md)을 참고해 주세요.

> 후속 평가: 이 기록 이후 같은 저장 답변으로 [한국어 역질문 재평가](FOURTH_RAGAS_KOREAN_RELEVANCY_RESULTS.md)를 완료했습니다. 기본 프롬프트 점수와 한국어 조건 점수를 구분해 확인해 주세요.

2026-09-18 KST. 평가 모델: `gpt-4.1-mini-2025-04-14`; 임베딩: `text-embedding-3-small`; 공식 RAGAS 0.4.3.

**추가 근거는 제한적이다. Dev의 근거 충실도 개선은 관찰됐으나, 재사용 Holdout의 뚜렷한 개선이나 질문 관련성의 일관된 우위까지 입증하지는 못했다. 기존 유형·행동 개선 근거를 보완하는 자료로 사용하고, RAGAS 전체 지표에서 Qwen이 우월하다고 주장하지 않는다.**

## 대상과 비교 조건

- 기존 Dev120과 재사용 Holdout120에서 사전 기대가 일반 답변인 20건과 정정인 20건씩 전부 선정했다. 총 80문항 × EXAONE/Qwen = 160개 응답이다. 실제 분류나 이전 성공 여부를 보고 문항을 고르지 않았다.
- 평가 대상은 저장된 최종 `ServiceResponse.message`다. 출력 유형, 모델 이름, 기존 검토 점수, 정정 구조 필드, 인용 목록을 답변 본문에 추가하지 않았다. 원시 모델 출력이나 화면 전체 품질을 채점한 결과가 아니다.
- 기존 답변과 검색을 재실행하지 않았다. 양 모델에 같은 저장 문맥을 제공했다. 일반/정정 외 기대 유형은 지표의 목적에 맞지 않아 제외했으며, 120건 또는 240건 전체 정확도로 환산하지 않는다.
- 공식 Faithfulness·AnswerRelevancy 클래스와 기본 프롬프트를 사용했다. 저장소의 같은 언어 역질문 지시는 사용하지 않았다. 관련성 strictness=3, 평가 temperature=0, 출력 한도4096이다.
- 동일 평가 모델을 양쪽에 적용하고 모델 신원·정답 라벨을 채점 입력에서 제외했다. 다만 문체로 모델을 추정할 수 있으며 독립 사람의 블라인드 평가를 뜻하지 않는다.
- 최초 160응답의 두 지표320개와 추가 제목 보존 Faithfulness160개 모두 완료했다. 실패·누락·재시도 없이 HTTP 성공했으며 실패를 0점으로 대체하지 않았다.

## 3. 유보 응답과 지표 해석

자료 부족을 정직하게 안내해도 추출된 주장이 근거와 맞으면 Faithfulness는 높게 나올 수 있다. 반면 AnswerRelevancy는 noncommittal 판정 때문에 0점이 될 수 있다. 그러므로 이 점수는 과업 해결률이 아니다.

- 잘못된 전제를 올바르게 반박하면 질문 표면과 답변의 의미가 달라질 수 있다. 정정 질문에서 관련성 점수를 정정 성공률로 읽으면 안 된다.

## 4. 판정 근거 점검과 한계

- HO2-037 조담환: 본문만 사용하면 Qwen 충실도0.0, 제목을 보존하면1.0이다. 제목이 빠진 평가 입력이 실제 모델이 받은 근거보다 불완전했던 사례다.
- DEV2-022 석굴암: 올바른 위치 정정에도 마지막 문장의 “질문의 전제와 실제 위치가 다르다”를 평가기가 질문 정보 부재로 감점했다. NLI 단계에는 문맥과 추출 주장만 전달되므로 정정의 메타 설명이 불리할 수 있다.
- DEV2-018 갑신정변: 평가기는 고종 폐립 유언비어를 실제 목표로 옮긴 문제를 감지했다. 기존 내용 검토에서 확인한 Qwen 회귀가 이 지표에도 드러난 사례다.
- HO2-040 청원군: 기존 내용 검토는 근거 없는 한자 병기를 지적했으나 RAGAS의 영어 주장 추출에서 해당 표기가 빠져 충실도1.0을 받았다. 주장 추출이 모든 오류를 보존하지는 않는다.
- HO2-039 해동여도: message만 평가하므로 별도 premise_correction 필드에서 나타난 다른 지도 속성의 전이는 이번 점수의 측정 대상 밖이다.
- 여러 사실을 섞은 문장, 자료의 주어·시기·대상 구분을 평가 모델도 오독할 수 있다. Faithfulness1.0은 무오류 인증이 아니다.
- 신뢰구간은 같은 질문 쌍을10,000회 재표집한 percentile bootstrap(seed20260918)이다. 평가 모델의 재호출 변동은 포함하지 않으며, 작은 표본·인위적 균형 세트·이미 사용한 Holdout에 대한 탐색적 분석이다. 여러 하위 비교에 대한 보정은 하지 않았다. 실제 사용자 분포·전체 사실 정확도·독립 검증으로 일반화하지 않는다.

## 5. PR에 권장하는 표현

> Qwen 전환은 기존 Dev·Holdout의 응답 유형 및 정정·되묻기 행동 평가에서 개선됐다. 일반 답변·정정 문항을 대상으로 공식 RAGAS 사후 평가를 추가한 결과, Dev에서 근거 충실도 개선을 확인했다. 다만 기존 Holdout의 충실도와 질문 관련성에서는 뚜렷한 우위를 확인하지 못했다. 따라서 모델 전환 권고의 주 근거는 기존 유형·행동 평가이며, RAGAS 결과는 제한적인 보조 근거로 제시한다.
