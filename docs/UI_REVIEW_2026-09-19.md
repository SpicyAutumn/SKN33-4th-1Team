## 적용 범위

- 실제 화면 코드: 오류 유형 드롭다운(기존 단일 유형 API 유지), 오류 패널 헤더/모바일 높이, 오늘의 문화유산 이미지 원본 비율 유지.
- 테스트 전용: 6가지 제안 유형, 기타만 설명 필수, 캡처 붙여넣기/파일 미리보기, 시도 지도 로딩. capturePreview 기본 false, loadingPreview 기본 null.
- 실제 검색 로딩은 기존 HeritageLoading을 유지. 최신 지도는 검토용 iframe으로 연결했으며 운영 통합 컴포넌트 전환 전 단계.
- 백엔드, 모델, 프롬프트, DB 및 환경변수 변경 없음. 캡처 파일은 전송하지 않음.

## 지도 자료와 한계

Natural Earth Admin 1 1:10m, Public Domain. 원본 https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson
이용 조건 https://www.naturalearthdata.com/about/terms-of-use/
KOR 17개 시도와 PRK 11개 내부 경계를 같은 투영식으로 표시. 정밀 안내가 아닌 지역 소개용. 최신 행정구역 변경(예: 군위군 대구 편입)과 작은 도서 반영 여부는 배포 전에 공식 경계 데이터로 추가 검토해야 함.
투영: x=275+(경도-128)*42*cos(38°), y=25+(43.5-위도)*42, viewBox 550×500.
SVG 경계는 테스트 HTML에 포함되어 있으며 전체 원본 GeoJSON은 PR에 포함하지 않음.
