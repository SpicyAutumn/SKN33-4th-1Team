# 실험 과정과 실제 응답을 함께 읽기

> 이 문서는 비상업 교육·연구 결과입니다. 아래 AI 응답에는 실제로 확인된 오류가 있습니다. 역사 사실을 안내하는 답변으로 사용하지 마세요.

## 전체 흐름

```text
생성 답변에서 사실 관계 오류 발견
  → 원문과 답변을 사람이 대조하고 12개 표본 판정 확정
  → 답변을 다시 검사하는 AI 검수 방식 준비
  → 첫 실제 검사: 오류 놓침과 인용 실패 확인
  → 의미·범위를 강조한 지시 B를 별도 후보로 작성
  → 기존 A와 같은 문항으로 비교
  → 사람 검수: 개선 미확인, B 미채택
  → 원문·실제 응답·실패와 한계를 함께 공개 자료로 정리
```

앞선 생성 프롬프트·근거 선택 실험은 이 검수 실험의 배경입니다. 이 자료에 수록한 실제 실행은 **첫 검수와 의미 보완 비교 두 세션**이며, 프로젝트의 모든 과거 실행 원본을 수록했다고 주장하지 않습니다.

## 무엇을 비교했나요?

A는 기존 검수 지시, B는 주체·관계·사용 범위·추정 강도를 원문대로 확인하라는 설명을 추가한 지시입니다. 정답은 AI에게 주지 않았습니다. 원문 전체 청크와 검사할 주장, 답변의 주변 문맥은 동일하게 유지했습니다. 주변 문맥은 사실 근거가 아닙니다.

- V02: 사용 대상을 원문보다 넓힌 주장을 걸러내는가?
- V01: 정상 주장에 올바른 판정을 유지하고 설명도 사실에 맞게 쓰는가?
- V03: 정상적인 추정 표현을 인정하는가? 직접 작성한 대조 예시입니다.

## 실제 응답과 사용자 검수

원문 전체 입력, 첫 검사·비교의 준비 호출까지 포함한 10개 출력은 [연구 증거 자료](../experiments/semantic_verifier/research_evidence.json)에 있습니다. 이 파일은 결과 보존 자료로, 실행 입력이나 다른 모델의 학습 데이터로 바로 사용하기 위한 파일이 아닙니다.

### V02-A

- AI 판정: `supported`
- 검사 대상: 주로 왕이나 고위 관료만이 사용할 수 있었던 물건이었습니다.

**AI가 작성한 설명 그대로:**

> 원문에서 공작선이 주로 왕이나 고위 관료만이 사용할 수 있었던 고귀한 상징물임을 명시하고 있으며, 918년에 공작선을 선물한 사람이 견훤임을 확인할 수 있습니다. 따라서 주장이 제공하는 맥락과 사실이 일치합니다.

### V02-B

- AI 판정: `supported`
- 검사 대상: 주로 왕이나 고위 관료만이 사용할 수 있었던 물건이었습니다.

**AI가 작성한 설명 그대로:**

> 원문에서 공작선이 주로 고귀한 상징물로서 왕이나 고위 관료만이 사용할 수 있었던 물건임을 명시하고 있습니다. 이는 대상 주장이 주장하는 내용과 일치하므로, 주장은 원문에 의해 뒷받침됩니다.

### V01-A

- AI 판정: `supported`
- 검사 대상: 패배한 측의 여성이 슬픔을 담아 '회소회소'라고 노래를 불렀다고 전해집니다.

**AI가 작성한 설명 그대로:**

> 원문은 패배한 측의 여성이 슬픔을 담아 '회소회소'라고 노래를 불렀다는 주장을 직접적으로 지지합니다. 특히 『삼국사기』를 통해 전해지는 이야기에서 신라 유리왕 시기의 왕녀들 사이에서 벌어진 삼을 삼기 경쟁에서 패배한 여성이 슬픔을 표현하며 '회소회소'를 불렀다고 명시하고 있습니다.

### V01-B

- AI 판정: `supported`
- 검사 대상: 패배한 측의 여성이 슬픔을 담아 '회소회소'라고 노래를 불렀다고 전해집니다.

**AI가 작성한 설명 그대로:**

> 원문은 패배한 측의 여성이 슬픔을 담아 '회소회소'를 불렀다는 주장과 일치합니다. 특히, 신라 시대 제2대 왕 유리왕 시기의 왕녀들 중 한 명이 패배한 상황에서 이 노래를 불렀다는 구체적인 맥락이 제공되어 있어 주장이 뒷받침됩니다.

### 사람이 확인한 결론

| 항목 | 최종 검수 의견 |
| --- | --- |
| V02 | A와 B 모두 사용 범위 오류를 놓쳤습니다. 원문 인용이 정확해도 결론은 잘못됐습니다. |
| V01 | 두 방식 모두 대상 판정은 맞습니다. A 표현에 모호함이 있을 수 있지만 B보다 원문에 부합합니다. B는 노래 부른 사람의 신분을 단정해 오류를 추가했습니다. |
| V03 | A는 원문을 이어 붙여 인용 검사에 실패했습니다. B는 실행되지 않아 비교 미완료입니다. |
| 채택 | B는 실제 서비스에 적용하지 않습니다. A도 자동으로 믿고 쓰도록 승인한 것은 아닙니다. |

## 공개본과 보존 원본의 차이

| 그대로 포함 | 제외 또는 형식 변경 |
| --- | --- |
| 실제 모델 출력 문자열 전체, 오류·생략 표시 포함 | 원시 파일의 개인 절대 경로와 서버 접속정보는 제외 |
| 당시 제공한 세 입력과 원문 청크, 정답 매핑 | 중복 HTTP 기록·환경 파일은 제외 |
| 4회 + 6회 호출, 응답 시간·측정치·미실행 목록 | JSON 파일의 묶음 구조와 들여쓰기는 공개용으로 변경 |
| 요청 내용 확인용 해시 | 공개본 파일 전체가 보존 원본과 같다는 주장은 하지 않음 |

현재 웹페이지를 다시 내려받아 옛 원문을 덮어쓰지 않았습니다. 공개본은 당시 저장된 자료에서 만들었습니다. 코드용 합성 예제는 이 실제 결과와 별개입니다.
