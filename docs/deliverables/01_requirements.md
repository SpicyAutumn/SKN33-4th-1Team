# 요구 사항 정의서

## 1. 목적과 대상 사용자

사용자가 한국의 역사·문화에 관한 질문을 하고, 선택한 설명 수준의 답변과 그 근거를 확인할 수 있도록 한다. 자료에 없는 내용을 사실처럼 제시하지 않고, 답변을 다시 읽거나 오류를 알리는 흐름을 제공한다.

| 사용자 | 주요 요구 |
|---|---|
| 비회원 | 가입 전에 질문하고 답변·출처 확인 |
| 회원 | 다른 접속 시점에도 본인 기록 확인, 오류 제보, 계정 관리 |
| 공유 링크 수신자 | 전달받은 질문·답변 열람 |
| 관리자 | 제보 처리 및 이용 현황 확인 |

관리자 인증은 일반 회원의 역할 필드와 별도로 구현되어 있다. 최종 권한 정책은 API 명세와 함께 확인한다.

## 2. 기능 요구사항과 수용 기준

수용 기준은 “이 기능이 요구대로 동작했는지 판단하는 조건”이다. 아래 항목은 코드가 존재하는 범위이며, 시험 통과를 의미하지 않는다.

| ID | 요구사항 | 확인할 수용 기준 | 시험 |
|---|---|---|---|
| FR-01 | 질문·설명 수준 선택 | 세 수준의 유효한 질문은 처리하고 빈 질문·허용 길이 초과는 거절 | IT-01 |
| FR-02 | 검색 근거 기반 응답 | 답변·보류·되묻기·정정 등을 구분하고 근거를 확인 가능 | IT-02 |
| FR-03 | 출처·사진 표시 | 원문 링크와 근거를 제공하고 사진이 없을 때도 답변 열람 가능 | IT-03 |
| FR-04 | 회원 인증·계정 관리 | 가입·로그인·정보/비밀번호 변경·탈퇴를 권한과 입력 조건에 따라 처리 | IT-04 |
| FR-05 | 결과 저장·재열기 | 회원과 비회원의 개인 결과를 권한에 따라 재조회하고 AI를 재호출하지 않음 | IT-05 |
| FR-06 | 공개 공유 | 소유자가 공유를 선택한 결과만 별도 주소로 공개 | IT-06 |
| FR-07 | 오류 제보 | 회원 본인의 저장 답변과 연결해 등록·조회 | IT-07 |
| FR-08 | 관리자 처리 | 관리자 인증 후 현황·검색·제보 조회, 제보 처리 반영 | IT-08 |
| FR-09 | 연관 자료 탐색 | 추천 이유와 후보 제공, 대상 미확인·후보 없음 상태 안내 | IT-09 |
| FR-10 | 응답 화면과 재질문 | 요약·본문·정정을 구분하고 추가 질문·수준 변경 시 문맥 전달 | IT-10 |

## 3. 품질 요구사항

| ID | 요구 | 확인 기준 |
|---|---|---|
| NFR-01 | 접근권한 보호 | 다른 사용자의 비공개 결과·제보와 관리자 기능 접근 차단 |
| NFR-02 | 근거 추적 | 제시한 문서·근거 ID와 실제 검색 결과의 연결 확인 |
| NFR-03 | 실패 안내 | 검색·생성·저장 장애를 성공처럼 표시하지 않음 |
| NFR-04 | 데이터 보존 | 테스트 재배포 전후 데이터 유지, 구조 변경 전 백업 |
| NFR-05 | 화면 가독성 | 좁은 화면·긴 답변·자료 없음 상태에서 핵심 조작 가능 |
| NFR-06 | 재현 가능성 | 코드·모델·데이터·설정 버전을 구분하여 기록 |

응답 시간의 합격 기준은 아직 확정하지 않았다. 측정값 없이 “빠른 응답”이라고 평가하지 않는다. 정상 검색·생성·기록 재조회는 각각 따로 측정한다.

## 4. 대표 이용 절차

1. 사용자가 질문과 설명 수준을 선택한다.
2. 서비스가 관련 자료를 검색하고 답변 유형과 설명을 구성한다.
3. 사용자가 요약·본문·근거·연결된 사진을 확인한다.
4. 개인 주소나 회원 기록에서 답변을 다시 읽는다.
5. 필요한 경우 공유하거나 오류를 제보한다.

## 5. 구현 범위와 제한사항

- 위치 인증·여행 경로 최적화·스토리 미션 등 과거 기획 기능.
- 자동 성향 분석 또는 본문으로 검증한 역사 관계 추천.
- 공유 링크 취소·만료 및 비회원 데이터 자동 정리.
- 모든 질문의 사실 정확도 보장, 기존 실험만으로 입증한 운영 모델 성능.
