**운영 서비스: [문화유산 AI 가이드](https://skn33heritage.site/)**

## 문서 간 연결

```mermaid
flowchart LR
    R["요구사항"] --> S["화면"]
    R --> A["시스템·ERD·API"]
    S --> T["통합 시험"]
    A --> T
    T --> P["실행 재현·최종 제출"]
```

요구사항은 화면과 API의 구현 범위로 연결되며, 테스트에서는 각 요구사항의 충족 여부를 확인한다.

검증 결과는 실제 실행 결과와 기존 보고서 인용을 구분한다. 미실행 시험과 확인이 필요한 데이터 구조는 해당 문서에 명시한다.
