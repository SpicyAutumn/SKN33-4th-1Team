## 2. 화면 이동 흐름

```mermaid
flowchart TD
    H["첫 화면"] --> Q["질문·수준 선택"]
    Q --> A["답변 화면"]
    H --> L["가입·로그인"]
    L --> M["마이페이지"]
    M --> P["검색 기록"]
    P --> A
    A --> S["공유 주소"]
    A --> R["오류 제보"]
    M --> R
    A --> N["연관 자료 선택"]
    N --> Q
    X["관리자 인증"] --> D["현황·검색·제보 관리"]
```

| 화면 주소 | 사용자가 보는 내용 | 접근 조건 |
|---|---|---|
| `/` | 질문 입력·설명 수준 선택 | 전체 사용자 |
| `/search/{결과 ID}` | 저장된 답변 다시 열기 | 회원 본인 또는 검색한 비회원 브라우저 |
| `/share/{공유 토큰}` | 공개를 선택한 답변 보기 | 링크를 받은 사람 |
| `/mypage`, `/mypage/security` | 내 정보·비밀번호·탈퇴 | 로그인 회원 |
| `/mypage/searches`, `/mypage/reports` | 내 검색 기록·오류 제보 | 로그인 회원 |
| `/admin`, `/admin/users`, `/admin/searches`, `/admin/reports` | 관리자 현황·목록·처리 | 별도 관리자 인증 |

주소는 브라우저 화면 주소다. 서버에 데이터를 요청하는 `/api/...` 경로와 구분한다. 마이페이지에서는 검색 기록과 제보의 상세 주소도 사용한다.

## 3. 답변 화면 구성 참고

아래는 정보 배치를 설명하는 개념도이며, 최종 화면 캡처가 아니다.

```text
┌──────────────────────────────────────┐
│ 질문 · 선택한 설명 수준                │
├──────────────────────────────────────┤
│ 정정 또는 추가 확인 안내(해당 시)       │
│ 핵심 요약                 [공유하기]  │
│ 전체 설명                             │
├───────────────────┬──────────────────┤
│ 근거 원문·내용      │ 연결된 사진·출처  │
├───────────────────┴──────────────────┤
│ 함께 알아보기: 추천 항목·추천 이유      │
│ 수준 변경 · 추가 질문 · 오류 제보      │
└──────────────────────────────────────┘
```

기본 오류 제보 화면은 유형을 한 개 선택하고 설명을 입력한다. 답변에서 드래그한 문구는 제보 내용에 추가된다. 서버는 여러 유형과 선택 문구의 별도 저장도 지원하지만, 기본 화면에서 그 입력 방식을 제공한다고 쓰지 않는다. 캡처 파일 첨부는 저장 API와 연결되지 않았다.

## 4. 화면 작성·검증 기준

| 조건 | 표시 기준 |
|---|---|
| 답변 생성 중 | 진행 상태와 재시도 가능 여부를 알리고 완료 답변처럼 보이지 않게 함 |
| 근거 부족 | 답변할 수 있는 범위와 보류 이유를 구분 |
| 정정 | 질문의 잘못된 전제와 이후 설명의 구분 확인 |
| 사진·추천 없음 | 빈 영역이나 오류 대신 해당 자료 없음 안내 |
| 개인 결과 접근 실패 | 다른 사람의 기록 존재 여부를 과도하게 노출하지 않음 |
| 공유 | 버튼 설명에 링크를 가진 사람이 질문·답변·출처를 볼 수 있음을 표시하고, 링크 복사 결과를 안내 |
| 과거 기록 | 저장하지 않았던 요약을 새로 생성한 것처럼 표시하지 않음 |
| 작은 화면 | 긴 제목·원문 URL·제보 입력에서 가로 넘침과 버튼 겹침 확인 |

화면의 실제 문구와 위 설계 기준을 대조한다. 예를 들어 `공유하기`의 버튼 설명과 복사 완료 알림은 현재 화면 코드에 있다.

## 5. 화면 증거 목록

| 캡처 | 포함 내용 | 상태 |
|---|---|---|
| SC-01 | 첫 화면·세 설명 수준 | 실제 화면 캡처 필요 |
| SC-02 | 정상 답변·근거·사진 | 실제 응답 캡처 필요 |
| SC-03 | 정정 또는 보류·되묻기 | 해당 질문 사례와 캡처 필요 |
| SC-04 | 기록 재열기·공개 공유 | 접근 권한을 구분한 캡처 필요 |
| SC-05 | 본인 제보·관리자 처리 | 테스트 계정의 캡처 필요 |
| SC-06 | 모바일·자료 없음·실패 | 상태별 캡처 필요 |

실제 사용자의 이름·이메일·질문을 촬영하지 않는다. 모의 응답을 사용했다면 캡처에 “모의 응답”임을 표시하고 실제 AI 시연과 구분한다.
