# 단일 주장 검증 — 후속 4문항 결과

## 먼저 읽을 결론

EXAONE과 Qwen 모두 기준 판단과 4개 중 3개가 일치했고, 인용 문구는 4개 모두 제공 자료와 정확히 일치했다. 그러나 오류 종류가 달라 두 모델이 동등하거나 Qwen이 일반적으로 우수하다고 결론 내리지 않는다. Qwen은 후속 검증 후보로 유지하고 운영 채택은 보류한다.

이 결과는 [PR #2의 기존 8개 사례](CLAIM_COMPARISON_PHASE1.md)와 별도다. 두 묶음을 합산해 서비스 정확도로 제시하지 않는다. 이번 PR은 문서 정리이며 서비스 동작을 바꾸지 않는다.

## 범위와 실행 조건

- 저장된 실제 출처를 바탕으로 사람이 작성한 4문항, 4문서, 3개 연결 그룹이다. IC02·IC03은 같은 출처 그룹으로 관리했다.
- 새로운 실제 검색 순위나 실제 생성 오류를 수집한 자료가 아니다. 전체 사용자 답변이 아닌 대상 주장 검증 실험이다.
- 모델: `exaone3.5:7.8b-instruct-q8_0`, `qwen3.6:27b-q8_0`.
- 모델 digest: EXAONE `dc6fcd786b422df5c72f0272faf26e54b5f93364e0e1b9e0ea8af22c30b4061d`, Qwen `cd0210c667bffa98ad702668d05fda1f340bcbb0a2c769bd389670d19ad1441b`.
- Ollama 0.34.0, NVIDIA A40, 각 모델 적재 전용 요청 후 평가. 평가 요청당 120초, 자동 재시도 없음.
- 평가 8회·적재 전용 2회 완료, 임베딩·검색 0회. 원문 응답과 서버 로그를 별도 보존했다.
- 실행 계획 SHA256: `ae7357e85c3a5e31c12ad64ffb901b7ae5ad3150f293dffd8d39cce0b6f137cf`.

## 답변 작성 기능과 구분할 점

IC01의 Qwen 응답에는 질문의 오류를 직접 부정하는 표현이 부족하다는 의견이 있었다. 그러나 이번 검사는 대상 주장이 출처와 맞는지 판단하는 역할이므로 기존 적합 판정을 유지한다.

실제 사용자 답변에서 틀린 전제를 명확히 바로잡는 기준은 [기존 구현·테스트 대응표](PREMISE_CORRECTION_REVIEW.md)로 따로 정리했다. 단일 주장 검증기에 답변 작성 역할을 추가하거나, 과거 결과를 새 기준으로 소급 변경하지 않는다.

## 공개 범위와 한계

실제 응답 원문·전체 출처 묶음·서버 로그·개인 경로·접속 정보는 이 PR에 포함하지 않는다. 따라서 이 문서만으로 실제 모델 결과를 독립적으로 재계산할 수 없다. 식별값은 동일성 확인용이지 판단 정확성의 보증이 아니다. 원문 공개 또는 추가 모델 호출은 별도 검토 사항이다.

이번 문서 PR에서는 코드·지시문·응답 구조·UI·기존 평가 점수를 변경하지 않는다. 테스트와 모델 호출을 새로 실행하지 않았다. 다음은 대응표의 제한된 확인 사항을 관련 담당자가 검토하고, 실제 변경이 필요한 경우 별도 범위를 정하는 단계다.
